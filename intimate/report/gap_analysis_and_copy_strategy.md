## 1. Unmet Needs & 결핍(Gap) 정밀 분석

현재 기준 제품인 **라엘(Rael) 천연 여성청결제**는 **"COSMOS 천연 인증"**과 **"단 8가지 전성분"**이라는 독보적인 클린뷰티 헤리티지를 보유하고 있으나, 상위권 경쟁사들과 비교할 때 **구매 결정을 가로막는 4대 핵심 결핍(Gap)**이 존재합니다.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        기준 제품 [라엘]의 4대 핵심 결핍(Gap) 진단                      │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  [Gap 1] 구체적인 항균(99.9%) 및 탈취(99%) 정량 수치 부재 ──► "정말 가려움/냄새가 없어질까?" 의구심 │
│  [Gap 2] 독자 바이옴/특허 메커니즘 부재 ─────────────► "단순히 물에 계면활성제 탄 기본 워시 아닌가?"│
│  [Gap 3] 제형의 부드러움 및 씻김성(Quick Rinse) 증명 부족 ─► "거품이 미끈거리거나 남지 않을까?"     │
│  [Gap 4] 친환경 리필/대용량 및 번들 혜택 부족 ─────────► "150ml는 너무 빨리 써서 번거롭다"          │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

| :--- | :--- | :--- | :--- |
| **1. 문제 해결 정량 데이터 결핍** | - 칸디다균 **99.99% 감소** (비레시피)<br>- 가드넬라균 **99.84% 감소** (비레시피)<br>- 트리메틸아민 **99.5% 탈취** (클리티)<br>- 보습 **66% 개선** (질경이) | - "순하게 세정해 준다"<br>- 피부 저자극 0.00 외 **항균/탈취 정량 시험 수치 일체 미표기** | **"순한 건 알겠는데, 내 생리 전후 가려움과 냄새까지 잡아줄 수 있을까? 효과가 약할 것 같아."** ➜ 문제 해결형 고객 이탈 |
| **2. 독자 기술 & 바이옴 스토리 결핍** | - KAIST D-만노스 부착 방어 (이너시아)<br>- 특허 Eve Solution™ (비레시피)<br>- 산부인과 테스트 & AMPamide™ (아토팜)<br>- 11개국 특허 바이옴-13 (질경이) | - 정제수, 글리세린, 코코베타인 등 **원료 사전식 단순 나열**에 그침<br>- 독자 특허나 차별화된 바이오 메커니즘 부재 | **"그냥 물에 식물성 거품제 섞은 흔한 기본 청결제 아닌가? 굳이 이 브랜드여야 할 이유가 없네."** ➜ 브랜드 가치 저평가 |

| **4. 패키지 용량 및 번들 가치 결핍** | - **150ml 본품 + 150ml 리필 파우치 기획** (바솔)<br>- 300ml / 500ml 메가 대용량 펌프 (유리아쥬, 클리티)<br>- 1+1 더블 번들 (메디온, 유리아쥬) | - **150ml 단품 위주 운영** (12,900원)<br>- 친환경 리필 파우치나 대용량 옵션 부재 | **"150ml는 한 달이면 다 쓰는데 계속 사기 번거롭고 플라스틱 쓰레기만 나오네."** ➜ 객단가 및 재구매 락인 한계 |

```

> **❌ 이탈 발생 원인 진단**:
> - 제품의 '스펙(전성분 8개, 인증)'을 단순히 나열한 **전형적인 '공급자 중심 설명문'**.

```
┌────────────────────────────────────────────────────────────────────────┐

│ 1단계: 3초 후킹   │ COSMOS 인증 + 칸디다 99.9% 항균 엠블럼 + 감각적 폼 비주얼│

### 📸 필수 추가/개선 시각화 컷 가이드

```

│ 1. 임상 성적서 실물 │ 2. 5초 퀵 린스 컷   │ 3. 8가지 원료 인포그래픽       │
│   · 칸디다 99.9% 성적서│   · 잔여물 0% 투명 비커│   · 8개 원료와 역할 한눈에      │
│   · 99% 소취율 그래프 │   · 쫀쫀 미세 버블 접사│   · COSMOS 인증서 원본          │
└───────────────────┴───────────────────┴────────────────────────────────┘
```

1. **임상 데이터 & 성적서 실물 시각화 (신뢰도 200% 상승)**:
   - 한국피부과학연구원/KOTITI **칸디다균 99.9% 항균 성적서 원본 스캔본** 배치.
   - 생리혈/분비물 악취 원인인 **트리메틸아민 99% 탈취 전후 비교 그래프** 노출.
   - D-만노스가 유해균의 점막 부착을 차단하는 **바이오 메커니즘 3D 일러스트** 삽입.
2. **제형 및 5초 퀵 린스(Quick Rinse) 사용감 증명**:
   - 펌핑 즉시 분사되는 **초미세 마이크로 버블의 탄력 있는 클로즈업 컷**.
   - 흐르는 물에 단 5~7초 만에 미끈거림 없이 씻겨 내려가는 **'잔여물 제로 퀵 린스' 비교 테스트 컷** (투명 비커 세정 실험).
3. **'단 8가지 전성분'의 투명 인포그래픽**:
   - 8개 성분의 EWG 그린 등급과 각각의 역할(정제수: 수분 베이스, 락틱애씨드: 약산성 유지, 코코베타인: 저자극 세정 등)을 **원형 다이어그램 인포그래픽**으로 직관화.
   - **COSMOS NATURAL 공식 인증서 실물**을 배치하여 위조 불가 신뢰성 확보.
